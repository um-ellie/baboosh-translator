# ببوش ترنسلیت (فارسی)

افزونه **ببوش ترنسلیت (Baboosh Translate)** یک ابزار کاربردی، تمیز و کاملاً حرفه‌ای برای مرورگرهای **گوگل کروم (Google Chrome)** و **موزیلا فایرفاکس (Mozilla Firefox)** است که با آپدیت بزرگ **نسخه ۳.۰** تبدیل به یک "مترجم جهانی" شده است.

---

## مهم‌ترین ویژگی‌های جدید (نسخه ۳.۰)

- **ترجمه چندزبانه (Multi-Language):** دیگر محدود به فارسی نیستید! می‌توانید متن‌ها را به زبان‌های فرانسوی، آلمانی، اسپانیایی، ایتالیایی و چینی ترجمه کنید.
- **تغییر لهجه صوتی (US / UK):** با یک کلیک بین لهجه استاندارد آمریکایی 🇺🇸 و لهجه بریتانیایی 🇬🇧 جابه‌جا شوید.
- **ترجمه معکوس هوشمند (Reverse Translation):** اگر زبان مقصد را روی فارسی تنظیم کرده باشید اما متنی فارسی را در سایت انتخاب کنید، افزونه هوشمندانه آن را تشخیص داده و به صورت خودکار به "انگلیسی" ترجمه می‌کند!
- **پخش صدای مجزا:** در باکس ترجمه، دو دکمه 🔊 مجزا برای متن اصلی و متن ترجمه شده وجود دارد. متن اصلی با لهجه انتخابی شما خوانده می‌شود و متن ترجمه‌شده مستقیماً با **زبان مقصد** (مثلاً با لحن ایتالیایی یا فرانسوی) تلفظ می‌گردد.
- **معماری Shadow DOM:** رابط کاربری افزونه حالا در یک محیط کاملاً ایزوله (Shadow DOM) اجرا می‌شود، به این معنی که دیگر استایل‌های سایت‌های مختلف، باعث به‌هم‌ریختگی ظاهر افزونه نخواهند شد.
- **پشتیبانی کامل از Dark Mode:** تمام بخش‌های برنامه (باکس ترجمه، منوی تنظیمات، و پاپ‌آپ) با سیستم حالت تاریک (Dark Mode) شما هماهنگ هستند.
- **بین‌المللی‌سازی (i18n):** تمامی متون منوها و گزینه‌های افزونه به صورت خودکار با زبان مرورگر شما (فارسی یا انگلیسی) تطبیق داده می‌شوند.

---

## ویژگی‌های کلاسیک

- **آیکون شناور و هوشمند پیشی**: با انتخاب (Select) هر متنی در صفحه، آیکون بامزه پیشی ظاهر می‌شود.
- **موقعیت‌یابی هوشمند (Smart Positioning)**: باکس ترجمه به گونه‌ای طراحی شده که هرگز از لبه‌های مرورگر بیرون نزند و روی متن اصلی قرار نگیرد.
- **مدیریت پخش صدا (Instant / On-Demand)**: امکان فعال یا غیرفعال‌سازی پخش خودکار صدا هنگام باز شدن باکس ترجمه.

## راهنمای نصب

### مرورگر فایرفاکس (Firefox)
این افزونه به صورت رسمی در فروشگاه افزونه‌های فایرفاکس (Firefox Add-ons Store) قرار دارد:
**[دریافت و نصب افزونه از فروشگاه رسمی فایرفاکس (AMO)](https://addons.mozilla.org/en-US/firefox/addon/baboosh-translate/)**

### مرورگر کروم (Google Chrome)
1. به بخش **[Releases](https://github.com/um-ellie/baboosh-translator/releases)** بروید و فایل `baboosh-translate-chrome.zip` را دانلود و استخراج (Extract) کنید.
2. مرورگر کروم را باز کرده و به آدرس `chrome://extensions/` بروید.
3. از گوشه بالا سمت راست، گزینه **Developer mode** را روشن کنید.
4. روی دکمه **Load unpacked** کلیک کنید و پوشهٔ استخراج‌شده را انتخاب کنید.

> **نکته:** پس از نصب، صفحاتی که از قبل باز بوده‌اند را یک بار Refresh کنید.

# Baboosh Translate (English)

**Baboosh Translate 3.0** is a modern, clean, and adorable extension for **Google Chrome** and **Mozilla Firefox** that turns into a smart, global translation powerhouse.

---

## What's New in Version 3.0?

- **Global Multi-Language Translation:** Translate selected text into Persian, Spanish, French, German, Italian, or Chinese using the beautiful new Dropdown menus.
- **British & American Accents:** Easily toggle between 🇺🇸 American (US) and 🇬🇧 British (UK) pronunciation styles via the Popup or Options page.
- **Smart Reverse Translation:** If your target language is Persian, but you highlight Persian text, Baboosh is smart enough to auto-detect the language and translate it *back* to English for you.
- **Dedicated Dual Audio Playback:** The translation box now features two 🔊 speaker icons—one to pronounce the original text in your preferred English accent, and one to pronounce the translated text in its native tongue (e.g. authentic French or Italian pronunciation).
- **Shadow DOM Isolation:** The entire popup UI is now wrapped inside a custom Shadow DOM. This guarantees that the extension will never inherit messy CSS from host websites, keeping the UI pristine everywhere.
- **Native Dark Mode Support:** The popup, options page, and translation box all perfectly adapt to your operating system's Dark/Light mode preferences.
- **Full i18n Localization:** The extension’s menus, settings, and buttons automatically adapt to your browser's language (English or Persian).

---

## Classic Features

- **Smart Floating Cat Action Icon**: Select any text on a webpage, and a cute cat icon pops up right beside your selection.
- **Intelligent Viewport Boundary Control**: The translation popup box dynamically calculates layout bounds to prevent overflowing off-screen edges or obscuring original text.
- **Flexible Audio Modes**: Choose between auto-play audio or on-demand manual audio playback.

## Installation Guide

### Mozilla Firefox - Official Add-ons Store
**[Install Baboosh Translate from Firefox Add-ons (AMO)](https://addons.mozilla.org/en-US/firefox/addon/baboosh-translate/)**

### Google Chrome
1. Go to the **[Releases](https://github.com/um-ellie/baboosh-translator/releases)** section, download `baboosh-translate-chrome.zip`, and extract it.
2. Open Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top-right corner.
4. Click the **Load unpacked** button and select the extracted folder.

> **Note:** If the extension does not trigger on web pages that were open prior to installation, simply reload (refresh) those tabs once.
